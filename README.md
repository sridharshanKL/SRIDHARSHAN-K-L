# Brain Tumor Segmentation

Brain Tumor Detection in MRI using PyNIB (Jupyter Notebook)

Overview

This project demonstrates how to detect brain tumors from MRI scans using Python and PyNIB (nibabel) within a Jupyter Notebook environment. It focuses on reading, visualizing, and analyzing 3D brain images in NIfTI format (.nii or .nii.gz) to identify tumor regions.

The approach is primarily based on image preprocessing and simple analysis logic, and is ideal for educational, research, or prototyping purposes.

Features

Interactive tumor detection workflow in a single Jupyter Notebook

Load and process MRI data using nibabel

Visualize brain slices and tumor-affected regions

Modular code cells for easy experimentation and customization


Technologies Used

Jupyter Notebook

nibabel (PyNIB) – for loading and handling medical image files

NumPy – for array and numerical operations

Matplotlib – for visualization of brain slices
